Как это работает

Почта направляется через разные SMTP-серверы в зависимости от адреса отправителя. Режим читается из main.cf.

Активный режим: {% if routing_mode == 'relayhost' %} Relayhost (B) — values saved as [host]:port {% else %} Transport (A) — values saved as smtp:[host]:port with per-route options {% endif %}
Файл map: {{ routing_map }} — смена режима в Конфигурации
