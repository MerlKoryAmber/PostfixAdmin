How It Works

Routes mail by recipient domain via /etc/postfix/transport (Postfix parameter transport_maps). This is not sender-based routing: From-address rules live in Routing.

Lookup order: user@domain → domain → .parent.domain (subdomains) → *.

Destination format: smtp:[host]:port. Examples:

  • example.com → smtp:[mx.example.com]:25 — that domain only
  • .example.com → smtp:[mx.example.com]:25 — subdomains
  • * → smtp:[outbound-relay.example.com]:587 — everyone else
