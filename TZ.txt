?? Техническое задание
1. Общие требования
Назначение системы: Веб-интерфейс для администрирования почтового сервера Postfix без необходимости прямого доступа к консоли сервера.

Целевая аудитория: Системные администраторы, DevOps инженеры, специалисты технической поддержки.

Требования к функционированию:

Работа исключительно по протоколу HTTPS

Автоматический редирект HTTP > HTTPS

Поддержка современных браузеров (Chrome, Firefox, Safari, Edge)

Адаптивный дизайн для мобильных устройств

2. Функциональные требования
2.1 Аутентификация и авторизация
Локальная база пользователей в JSON формате

Два уровня доступа: администратор и пользователь

Хеширование паролей (SHA256)

Защита от перебора учетных записей

Управление пользователями через CLI

2.2 Управление конфигурацией Postfix (main.cf)
Просмотр и редактирование основных параметров

Валидация вводимых значений

Автоматическое создание резервных копий

Восстановление из бэкапа

Проверка конфигурации перед применением

Перезагрузка Postfix после изменений

2.3 Управление транспортной картой (transport)
Просмотр всех записей транспортной карты

Добавление новых маршрутов

Удаление существующих записей

Валидация формата доменов и транспорта

Автоматический запуск postmap

2.4 Маршрутизация по отправителю (sender_transport)
Управление правилами маршрутизации

Настройка аутентификации для каждого отправителя

Конфигурация TLS для отдельных маршрутов

Привязка к IP-адресам

Тестирование маршрутов через postmap -q

2.5 Просмотр логов
Отображение последних 500 строк maillog

Фильтрация по типу сообщений

Поиск по содержимому

Автообновление каждые 30 секунд

Цветовое выделение в стиле терминала

3. Технические требования
3.1 Программный стек
Backend: Python 3.9+, Flask 3.0

WSGI сервер: Gunicorn

Веб-сервер: Nginx (reverse proxy)

База пользователей: JSON файл

ОС: CentOS 9 / Rocky Linux 9

3.2 Безопасность
Обязательный HTTPS с HSTS

TLS 1.2/1.3 с сильными шифрами

Secure и HttpOnly cookies

Защита от XSS, CSRF, clickjacking

Санитизация пользовательского ввода

Атомарная запись конфигурационных файлов

Блокировка файлов при записи

3.3 Производительность
4 worker процесса Gunicorn

Кеширование статических файлов

Ограничение на чтение логов (500 строк)

Таймауты для внешних команд

4. Требования к интерфейсу
Единый стиль оформления

Адаптивная верстка (Bootstrap 5)

Понятная навигация

Информативные сообщения об ошибках

Подтверждение опасных действий

Индикация статуса сервера
